# LinBackup

Copia tus carpetas a un SSD externo en cuanto lo enchufas. Reconoce el disco por su UUID, aparta lo borrado en vez de eliminarlo y compara byte a byte antes de mover nada.

Versión para Linux de [BackupSSD](https://github.com/baltamir1978/BackupSSD), la app de macOS. No es un port:
se escribe desde cero, con la app original como especificación.

**Estado: sin empezar** (21-oct-2026).

## Pila

Python 3 + GTK 4 + libadwaita, para **Debian 13 con GNOME**. Se instala con un paquete `.deb`.
